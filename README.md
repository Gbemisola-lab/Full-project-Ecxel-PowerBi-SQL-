## 📝 Overview

This presentation summarizes a data analytics assessment based on customer data from a fashion store and a supermarket. The goal was to derive business insights and strategic recommendations using Excel, SQL (with subqueries), and Power BI.

## 📂 Contents

- `Gbemisola's Data Analytics Assessment. PowerPoint.pptx` – Main presentation file
  

## 🔍 Key Insights

### Fashion Store:
- Most sales came from Medium and Large sizes
- Customers aged 27–35 were top spenders
- Spending was concentrated in urban centers like Lagos and Abuja

### Supermarket:
- 60% of customers were above-average spenders (₦12,700+)
- Customer "Chuka Obi" identified as highest spender
- Spending status segmented using SQL subqueries

## ✅ Recommendations

- Optimize fashion store inventory for popular sizes
- Launch targeted marketing for 27–35 age group
- Reward top spenders and expand in high-revenue locations
- Use subquery-based segmentation for supermarket offers
